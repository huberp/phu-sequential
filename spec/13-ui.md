# ARP Plugin Specification v2 - UI

## 14. UI

The editor is a single resizable window. A global bar at the top holds Thru, Consume, Chord Input Channel, and the preset browser. Below it, 8 lane rows are stacked, with vertical scrolling if they do not fit. Each lane row has a control strip with all lane parameters (Section 12), the Timing Source switch, and a color picker for the lane color, plus the step display and the text-grid field. The lane color is used for the lane's steps: the on-state step pads and the velocity drag bars are drawn in the lane color; off steps are drawn neutral. Lane number and other lane UI elements may use the lane color as accent. Colors are shown at the same time for all lanes so lanes are distinguishable at a glance. The lane color does not change any other lane's color.

The step display shows the width proportions of the active timing source. All lanes share one common time scale: the lane with the longest loop (loop length in beats, Section 5) defines the maximum lane width, which is the available width of the step area, and the width of every other lane is its loop length times the same scale (pixels per beat). A shorter lane is therefore visibly shorter than the longest lane, and equal note values have equal width in all lanes. For example, with 1/8 steps, a lane with 12 steps is exactly four 1/8-step widths wider than a lane with 8 steps, and a lane with 7 steps is one 1/8-step width narrower than the 8-step lane. The scale is recomputed whenever the longest loop changes (grid, step count, or Timing Source change). Swing does not change the displayed step widths. If the scale would make a step narrower than the minimum step display width (a named constant), the scale is clamped to that minimum, and the step area of all lanes scrolls horizontally together. Each step can be toggled on/off by clicking. Each step has a vertical drag bar for editing its velocity value; the drag bar range follows the active velocity mode (0 to 127, -127 to +127, or 0 to 200 percent) and shows the numeric value while dragging. In incoming velocity mode the drag bars are disabled. Each lane shows a playback position indicator. The text grid is presented as editable per lane and is validated (Section 5.3); it is editable regardless of the active Timing Source. While Timing Source is Text Grid, the base-timing controls (Base Timing, Subdivision, Swing, Step Count) are shown disabled.
